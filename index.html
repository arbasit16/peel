Why now

The clock is running on DYMO's Mac software.

  1. Now

    DYMO marks its older Mac software obsolete.

    DYMO Label v8 carries DYMO's own note: "This software version is obsolete."

    Source: DYMO
  2. macOS 27

    Even DYMO Connect leans on Rosetta.

    DYMO says its current Mac app relies on Rosetta on Apple Silicon Macs, which now has to be installed by hand.

    Source: DYMO
  3. macOS 28 · 2027

    Apple phases Rosetta out.

    From macOS 28, Apple keeps Rosetta only for certain older games, and DYMO says its older drivers don't work on Apple Silicon without it.

    Sources: Apple, DYMO

And DYMO Connect, the replacement, is clunky for everyday labels. Peel is built to fix that.

What Peel does today

A label designer that feels like a Mac app.

Only what works in the current build is listed here.

  • Type right on the label

    Drag things into place with guides, and undo anything.

  • Native for Apple Silicon

    Built for Apple Silicon Macs. No Rosetta needed.

  • Barcodes included

    Add barcodes to any label, at no extra cost.

  • Labels from a spreadsheet

    One label per row of a CSV, names and addresses filled in.

  • Dates and serial numbers

    Today's date, or a number that counts up as you print.
